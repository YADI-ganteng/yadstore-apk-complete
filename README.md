# YadStore APK

## 📱 Support Android
- ✅ Android 5.0 (Lollipop) - API 21
- ✅ Android 6.0 (Marshmallow) - API 23
- ✅ Android 7.0 (Nougat) - API 24
- ✅ Android 8.0 (Oreo) - API 26
- ✅ Android 9.0 (Pie) - API 28
- ✅ Android 10 - API 29
- ✅ Android 11 - API 30
- ✅ Android 12 - API 31
- ✅ Android 13 - API 33
- ✅ Android 14 - API 34

## 🔧 Fitur
- Login/Register dengan Firebase
- 8 Game (ML, FF, PUBG, Genshin, HSR, Valorant, Roblox, Steam)
- Top Up dengan harga diskon
- 3 Metode Pembayaran
- Riwayat Pesanan
- Profile User

## 📥 Download APK
- Debug APK: Actions → Build → Artifacts
- Release APK: Releases

## 🔧 Build
```bash
./gradlew assembleDebug
./gradlew assembleRelease
```
